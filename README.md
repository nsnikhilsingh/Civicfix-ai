# CivicFix AI

CivicFix AI is a web-based civic issue reporting project that helps citizens report local problems such as potholes, garbage, broken streetlights, and water leakage.

## Features

- Submit civic complaints using a web form
- Simple and user-friendly interface
- Complaint count display
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` - Main webpage
- `style.css` - Website styling
- `script.js` - Interactive functionality

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.

## Future Improvements

- Save complaints in a database
- Track complaint status
- Add an admin dashboard
- Add AI-based complaint categorisation

## Project Status

This project is currently a front-end prototype.
